# 온살 하카이르 3D 전술 보드

파이널 판타지 14 전장 **온살 하카이르(계절끝 합전)** 의 지형을 3D로 근사해서, 본대 위치·진격 경로·퇴로를
직접 핀과 화살표로 배치하며 설명할 수 있는 웹 도구입니다. (비공식 팬 툴)

## 실행

```bash
npm install
npm run dev
```

## 기능

- **지형**: 고저차가 있는 3D 지형 (1시 고원, 센언 단상과 다리, 11시 단상과 물길, 서쪽 협곡 돌다리, 2언/4언/7언 언덕, 바위)
- **유닛 핀**: 본대(큰 원) / 소수(작은 원)를 놓고 드래그로 이동. 색은 본진(1시/10시/6시)에 배정된 총사령부 색
- **경로 그리기**: 진격(실선 화살표), 퇴로(점선, 흐르는 애니메이션) — 지형을 따라 그려지고, 언덕 뒤에 가려진 부분은 반투명하게 비침
- **방어 위치(X/Y/Z 박스)**, **메모**
- **노드(순결한 땅) 13곳**: 클릭하면 B → A → S 등급 표시
- **단계(슬라이드)**: "다음 단계"로 현재 배치를 복사 → 유닛을 옮기면 단계 전환 시 이동 애니메이션. ▶ 재생으로 순서대로 설명
- **카메라**: 탑뷰 / 쿼터뷰 / 각 본진 시점 / 유닛 위치 시점, 시야각(FOV), 높이 과장 배율
- **공유**: 링크 복사(시나리오가 URL에 압축되어 들어감), JSON 내보내기/가져오기, 브라우저 자동 저장
- **지형 편집 모드**: 언덕·다리·영역·바위·노드 핸들을 드래그하고 높이/크기/경사를 슬라이더로 보정.
  게임 지도 스크린샷을 지형 위에 겹쳐서(투명도·크기·회전·위치 조절) 맞출 수 있음

## 단축키

| 키 | 동작 |
|---|---|
| V / 1 / 2 / 3 / 4 / 5 / 6 / E | 선택 / 본대 / 소수 / 진격 / 퇴로 / 방어 / 메모 / 지우기 |
| ← → | 이전/다음 단계 |
| Delete | 선택 삭제 |
| Ctrl+Z | 되돌리기 |

## 지형 데이터

`src/mapData.js` — 700×700 지도 픽셀 좌표 기준. 지형은 `features` 를 순서대로 덮어써서 만듭니다
(원형 언덕, 다각형 영역, 폭 있는 길/경사로, 물, 외곽 벽). 편집 모드에서 내보낸 JSON 으로 교체할 수 있습니다.

현재 지형은 게임 내 지도와 커뮤니티 공략 설명을 바탕으로 한 **근사치**입니다. 높이 수치는 추정값이며,
인게임 스크린샷(미니맵 위치·방향 + 그 방향 화면)을 기준으로 계속 보정할 예정입니다.

## 배포

`main` 브랜치에 푸시하면 GitHub Actions 로 GitHub Pages 에 배포됩니다.
(저장소 Settings → Pages → Source 를 **GitHub Actions** 로 설정해야 합니다.)
